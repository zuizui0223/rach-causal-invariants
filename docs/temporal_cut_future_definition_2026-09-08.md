# CCOC future responsibility at a temporal cut — definition firewall

## Purpose

This note fixes the mathematical meaning of the **future** side used when CCOC is projected into CREST. It is a claim-control note, not a new theorem.

The key rule is that the future responsibility must be defined on the declared raw controlled system **before** any ecological state quotient is constructed.

## Primitive objects

Fix a finite deterministic controlled system

\[
\mathcal M=(S,A,T,h),
\]

where `S` is the raw finite configuration space, `A` the primitive action alphabet, `T` the transition law, and `h` the focal observation/output map.

A declared legal future grammar is an exogenous set

\[
\mathcal L\subseteq A^*.
\]

For `s in S` and `w in \mathcal L`, let

\[
\operatorname{Tr}_{\mathcal M}(s,w)
\]

be the output trace generated by applying `w` from raw configuration `s`.

Define the future-response profile

\[
\rho^{\mathcal M}_{\mathcal L}(s)
:=
\bigl(\operatorname{Tr}_{\mathcal M}(s,w)\bigr)_{w\in\mathcal L}.
\]

This profile exists before any quotient state is chosen.

## Future equivalence

The CCOC future equivalence is

\[
s\equiv^{\mathcal M}_{\mathcal L} s'
\iff
\rho^{\mathcal M}_{\mathcal L}(s)
=
\rho^{\mathcal M}_{\mathcal L}(s').
\]

Equivalently,

\[
s\equiv^{\mathcal M}_{\mathcal L} s'
\iff
\forall w\in\mathcal L,
\operatorname{Tr}_{\mathcal M}(s,w)
=
\operatorname{Tr}_{\mathcal M}(s',w).
\]

Only after this relation has been defined do we form

\[
Q_{\mathcal L}=S/\!\equiv^{\mathcal M}_{\mathcal L}.
\]

Thus the response interface is **derived from** the primitive controlled system and future grammar; it is not used to define them.

## Why this is non-circular

The dependency order is

\[
(S,A,T,h),\ \mathcal L
\longrightarrow
\operatorname{Tr}
\longrightarrow
\rho_{\mathcal L}
\longrightarrow
\equiv_{\mathcal L}
\longrightarrow
Q_{\mathcal L}.
\]

There is no arrow from `Q_L` back into `L`, `T`, or the trace definition. In particular, the legal future grammar is a declared scientific/operational contract, not a set inferred from the state quotient it later induces.

This is the precise sense in which CCOC is a **future-responsibility** theory at a temporal cut. The future is not an additional state variable sitting to the right of time `t`; it is the family of right-of-cut counterfactual response queries that the state must support.

## Quantifier firewall against MRM

CCOC and MRM can both use future responses without being the same mathematical axis.

CCOC fixes the controlled law `M` and asks how raw configurations are identified under a declared grammar:

\[
\text{CCOC:}\qquad
\mathcal M\ \text{fixed},\quad
s,s'\ \text{vary},\quad
\mathcal L\ \text{declared/compared}.
\]

MRM instead fixes a visible macrostate space and declared intervention grammar while varying retained candidate laws `theta`.

So the two relevant equivalences quantify over different coordinates:

\[
\text{CCOC compares initial/raw configurations under one law};
\]

\[
\text{MRM compares latent laws behind one visible configuration}.
\]

A CREST interaction theorem may combine these responsibilities on one common carrier, but it must not identify the CCOC grammar with the MRM mechanism coordinate.

## Relation to the temporal cut

Given a CREST world `omega` at cut `t`, a CCOC application may supply a raw controlled configuration `s_t(omega)` in one fixed declared system `M`. For a chosen future grammar `L`, the right-of-cut responsibility map is

\[
F_{t,\mathcal L}(\omega)
=
\rho^{\mathcal M}_{\mathcal L}(s_t(\omega)).
\]

Two same-cut worlds may therefore require different CREST states when this map differs, even if the visible observation `O_t` agrees.

## Scope

This note does not add continuous time, stochastic dynamics, inferred action grammars, or empirical validity. It only fixes the non-circular dependency order already used by the finite CCOC theorem spine.
